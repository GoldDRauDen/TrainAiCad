# 521028-17 — a 90° corner closed from rounded dimensions is not "exactly 90"

Rule: `rules/CORNER_RC.md` §3; executable `tools/corner_guard.py` (`AUTO_R_MAX_DEG`), `tests/test_build_canonical.py`. Approved by the user (DUYỆT).

## FACT
- 26-063996 (SPHCP t6): tip drawn from 30 / 50 / 61.8 / 9.2 / 38°. The closed tip reads 90.009°; the sample has R2 there, my DXF kept it sharp.
- The old test was `deg <= 90 + 1e-6`, so the tip was neither rounded nor listed in `corner_inventory`.

## ROOT_CAUSE
`TOOL_TOLERANCE_TOO_TIGHT`: printed dimensions are rounded, so a perpendicular corner lands a hair above 90°.

## LESSON
Automatic Laser R applies to every uncalled convex outside corner up to 93° (all customers; a customer's own sharp/R rule still wins). A vertex above that is a drawn angle, not a rounding artefact.
