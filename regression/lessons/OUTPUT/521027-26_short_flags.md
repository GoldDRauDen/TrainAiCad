# 521027-26 — FLAG only a real difference, one short line

FACT: the report carried long FLAG lines for decisions the user had already ruled (milled recess not cut, struck locating-pin Ø8,
SK85 = SK) and a DATA/PDF flag with a Δ, threshold and "xác nhận với khách" tail.

ROOT_CAUSE: every uncertainty was routed to FLAG; a decision is not a difference.

LESSON: FLAG = DATA vs PDF beyond the gate or DATA vs a rule, written as `Lệch PDF <what>: DATA a / PDF b`. Decisions are ledger rows.
