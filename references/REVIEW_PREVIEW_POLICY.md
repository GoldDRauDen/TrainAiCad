# Review / preview / VIEWS_ONLY policy (single statement; was repeated in DRAWING_READING, VALIDATION and CAD_OUTPUT)

Applies only to a part with an unproved dimension, feature type, topology or datum after full source exhaustion (`DATUM_DIMENSION.md` §4.4, `HOLISTIC_ENGINEERING_CHALLENGE.md`). It never weakens production PASS gates and never permits silent geometry invention.

1. **DRAW -> FLAG -> CONFIRM.** If PDF evidence supports a recognizable approximation, draw the provisional portion Magenta (Layer 0, color 62=6) with an adjacent explicit FLAG note and ask after showing it. Keep every independently proved entity exact. Estimated numeric values are integer-rounded; unknown identity/topology is never output as speculative production geometry.
2. **Local FLAG precedence.** A source-proved flat stays; isolate only the unresolved feature (for example Magenta `CIRCLE` with `Ø?` and a coordinate FLAG). Never turn an unknown Ø into a capacity POINT. A local FLAG cannot force `VIEWS_ONLY`.
3. **VIEWS_ONLY** only after the holistic re-solve and source exhaustion. Then DRAW THE PROVED VIEWS: keep every proved source-view member as a separate labeled subgroup under the correct code (`<CODE> VIEW <id>`), preserve physical DATA curves, keep all proved features, FLAG only the unresolved relationship. Missing a proved member is `VIEWS_ONLY_SOURCE_VIEW_COMPLETENESS` FAIL; do not stop at a text report or emit a representative subset. Stop and ask only when no source view can be identified or the code identity is ambiguous.
4. **Status and file.** `PREVIEW`, `VIEWS_ONLY` and `FLAGGED` are never `PASS`. Any such part makes the composite `<JOB>_ALL_REVIEW_ONLY.dxf` with the global `REVIEW ONLY - NO CUT - UNRESOLVED CODES PRESENT` note; other codes keep their proved geometry. A prior user QA PASS does not certify a later changed file; full Section 5 validation is required once the uncertainty is resolved.
5. **Text.** `TEXT` is allowed only for an adjacent Magenta review warning; code/status labels use non-plot `AI_META`.
6. **Sample/reference.** A sample may verify but never supply a missing source fact. Sample FLAG/Magenta geometry declared pending is `CUSTOMER_CONFIRMATION_PENDING`, not manufacturing geometry. Explicit user QA closes only its specific question.
7. **Hole-family cancellation** is not a review state: see `DRAWING_READING.md` (V4.8) and `VALIDATION.md`.
