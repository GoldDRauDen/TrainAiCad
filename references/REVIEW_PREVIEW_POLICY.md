# Review / preview / VIEWS_ONLY policy (single owner; other files point here)

Applies to any part with an unproved dimension, feature type, topology, datum, bend order or Nobi after full source exhaustion (`DATUM_DIMENSION.md` §4.4, `HOLISTIC_ENGINEERING_CHALLENGE.md`). It never weakens production PASS gates and never permits silent geometry invention: Magenta is review geometry, never production geometry.

0. **ALWAYS DRAW, NEVER STOP (user-approved 2026-10-21).** A job never stops to ask and never leaves a code undrawn. Every code in the job appears in the composite: proved geometry exact, the uncertain part drawn as the best source-supported estimate in Magenta with a Vietnamese FLAG, status REVIEW. Questions for the user/customer are listed in the report **after** the DXF is delivered, never instead of it.
1. **DRAW -> FLAG -> CONFIRM.** Draw the provisional portion Magenta (Layer 0, color 62=6) with an adjacent `FLAG:` note. Keep every independently proved entity exact. Estimated numeric values (size, position) are integer-rounded; explicit and formula-derived values keep full precision.
2. **Local FLAG precedence.** A source-proved flat stays; isolate only the unresolved item. Missing hole data: draw a Magenta `CIRCLE` at the estimated Ø and position (scaled from the drawing, integer-rounded) plus a FLAG naming what is missing; never turn an unknown Ø into a capacity POINT and never omit the hole. A local FLAG cannot force `VIEWS_ONLY`.
3. **Competing candidates.** When two topologies, bend orders or attachment edges remain plausible after trace exhaustion, draw the candidate with the most source support in Magenta and name the alternative in the FLAG. Missing Nobi follows `SPLIT_FLANGE_10MM` (`BEND_UNFOLD.md` §4.7). Never use a bounding rectangle as a placeholder for an unknown contour.
4. **VIEWS_ONLY** only when no defensible flat candidate exists after the holistic re-solve and source exhaustion. Then draw the proved views: every proved source-view member as a separate labeled subgroup under the correct code (`<CODE> VIEW <id>`), physical DATA curves preserved, all proved features kept, FLAG only the unresolved relationship. Missing a proved member is `VIEWS_ONLY_SOURCE_VIEW_COMPLETENESS` FAIL; do not stop at a text report or emit a representative subset. An ambiguous code identity is drawn under a provisional label `<CODE>?` with a FLAG; only a source with no identifiable view at all is reported without geometry.
5. **Status and file.** `PREVIEW`, `VIEWS_ONLY` and `FLAGGED` are never `PASS`. Any such part makes the composite `<JOB>_ALL_REVIEW_ONLY.dxf` with the global note `CHỈ XEM XÉT - KHÔNG CẮT - CÒN MÃ CHƯA GIẢI QUYẾT`; other codes keep their proved geometry. A prior user QA PASS does not certify a later changed file; full validation is required once the uncertainty is resolved.
6. **Text.** All DXF notes are Vietnamese (`AGENTS.md` §6): `FLAG: <nội dung>` lines and adjacent Magenta notes, e.g. `Kích thước ước lượng - kiểm tra bản vẽ`, `M6 hoặc M8?`. Identifiers (codes, entity IDs, Japanese source text) stay verbatim. `TEXT` is allowed only for these notes; code/status labels use non-plot `AI_META`.
7. **Same-family undimensioned notch/step.** In a chain-dimensioned outline, an undimensioned notch/step of the same visible family takes the dimensioned one's size (drawing convention); record it as `DERIVED_FROM_SIBLING` in the member ledger and FLAG only when the drawing visibly differs.
8. **Sample/reference.** A sample may verify but never supply a missing source fact. Sample FLAG/Magenta geometry declared pending is `CUSTOMER_CONFIRMATION_PENDING`, not manufacturing geometry. Explicit user QA closes only its specific question.
9. **Hole-family cancellation** is not a review state: see `skills/lispcad/features/REVISION_CANCELLATION.md`.
10. **Measurable source is not a review reason.** A rotated/auxiliary view or an unlabeled inside/outside dimension that can be measured in the DXF is measured and joined (`ORTHO_PROJECTION_OD_SEPARATION.md`); PREVIEW/FLAG is only for what remains unproved after that. Never describe an existing DXF entity as unclear.
