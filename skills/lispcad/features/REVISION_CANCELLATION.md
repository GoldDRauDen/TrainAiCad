# LISPCAD Feature Router — revision / cancellation scope

Use when a callout, quantity, tolerance/finish, feature symbol, code or leader is crossed out, revised, replaced or otherwise ambiguous.

This module adds no new cancellation rule. Apply the active core drawing-reading rules and the approved `../../../regression/datum/520709-07_APPROVED.md` whole-family cancellation regression.

A complete feature family is deleted only when the cancellation scope and target leader are unequivocal under the approved rule. A partial tolerance/finish strike-through or unclear leader does not authorize deletion. Record canceled source quantity and verify zero residual manufactured entities for a confirmed full-family deletion.
